# Kudoby Deck Developer Community

Welcome to the **Kudoby Deck** creator and developer ecosystem!

Whether you are designing custom broadcast plugins, writing OBS Studio scripts, building virtual rotary dials, or integrating smart home and IoT devices, you've come to the right place.

---

## 💬 Community Channels

- **Official Discord**: [https://discord.gg/kudobydeck](https://discord.gg)
  - `#announcements`: Real-time SDK release announcements and protocol updates.
  - `#plugin-showcase`: Share your `.kudobyplugin` bundles and hardware creations.
  - `#sdk-support`: Get direct debugging assistance from our core engineering team.
  - `#feature-requests`: Propose new APIs, virtual dials, and hardware protocol bridges.
- **X (Twitter)**: [@kudobydeck](https://twitter.com)
- **Official Documentation**: [https://kudobydeck.com/docs/](https://kudobydeck.com/docs/)
- **Live Hardware Simulator**: `npx @kudobydeck/deck-sdk simulate`

---

## 🛠️ Getting Started in 30 Seconds

Bootstrap your first plugin using the official CLI:

```bash
npx @kudobydeck/deck-sdk create my-custom-plugin
cd my-custom-plugin
npm run simulate
```

# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.6.x   | :white_check_mark: |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

The Kudoby Technologies security team takes the safety of the Kudoby Deck ecosystem seriously. If you discover a security vulnerability in this SDK or the core daemon, please report it responsibly.

### Disclosure Process

- **Email:** Send full technical details to **support@kudobydeck.com**.
- **Response Window:** Our security engineering desk acknowledges receipt within **24 hours**.
- **Fix Timeline:** Validated vulnerabilities will be addressed in a patch release within **7 business days**.

Please do not report security vulnerabilities through public GitHub issues.
